# Guía actual del laboratorio de química

La entrega actual es el Laboratorio 1 de vinagre y bicarbonato: [mano flexionada, selección y continuidad](MANO_FLEXIONADA_Y_CONTINUIDAD.md).

La práctica incorpora un [Asistente de química local](ASISTENTE_QUIMICA.md) con preguntas, reglas y modo de pruebas. Se abre desde el HUD de Química o el cuaderno.

Abre `2_PROBAR_LAB3D.bat` con webcam o `7_RECORRER_LABORATORIO.bat` con ratón. Banco → Química → Preparar vaso → Añadir bicarbonato → Verter la dosis → Observar reacción → Ver cuaderno → Anotar ensayo. Al guardar aparece «Laboratorio completado» y puedes repetir.

Por defecto hay 100 mL de vinagre al 5 % m/v, vaso de 150 mL, 3 g de bicarbonato y dosis de 25 mL. Puedes elegir 50 mL para comparar. El cálculo usa el volumen realmente recibido; el alcohol es solo práctica de transferencia.

Abierta para apuntar/soltar, pinza para agarrar, muñeca para inclinar. Cualquiera de las manos puede agarrar cualquiera de los objetos. Con ratón, mantén clic para arrastrar y usa la rueda para inclinar. Una mano perdida congela su objeto y exige abrirse antes de recuperar el agarre. La otra conserva su control.

El cuaderno conserva su bitácora local (`user://bitacora/ensayos`), los textos de pregunta, hipótesis, observaciones y conclusión, las cantidades y el resultado teórico. B abre el cuaderno, Esc cierra; hay botones para pasar ensayos y un deslizamiento horizontal con mano abierta. Pulgar–medio cierra el panel activo.

Las [mediciones de estabilidad anteriores](VERIFICACION_DEMO_QUIMICA.md) se conservan como referencia. La auditoría detector–juego de esta entrega está en [LAB1_AUDITORIA_MANOS.json](LAB1_AUDITORIA_MANOS.json). La webcam real y la aceptación por Godot se midieron; el recorrido completo con manos físicas requiere confirmación humana. Los ensayos completos y el respaldo de ratón se automatizaron y están documentados en la entrega.
